# 温度、风扇、电压告警处理规范

## 1. 概述

服务器环境传感器是保障硬件稳定运行的基础监控体系。本规范覆盖三大类传感器：

| 传感器类型 | 监控目标 | 故障影响 |
|-----------|---------|---------|
| 温度传感器 | CPU 温度、进风口温度、硬盘温度、主板热点温度 | 高温加速芯片老化、触发降频保护、严重时导致宕机或永久损坏 |
| 风扇传感器 | 各风扇模块转速、风扇冗余状态 | 风扇故障导致散热失效，温度快速攀升，可能引发连锁硬件故障 |
| 电压传感器 | 12V/5V/3.3V/CPU核心电压/内存电压 | 电压偏离导致硬件误动作、逻辑错误、严重时烧毁电路 |

所有传感器数据通过 IPMI BMC 的 `ipmitool sdr` 命令采集，传感器状态遵循 IPMI v2.0 规范定义。

## 2. 监控指标

| 指标名称 | 说明 | 采集方式 |
|---------|------|---------|
| CPU 温度 | CPU 封装或核心温度传感器 | `ipmitool sdr type Temperature` |
| 进风口温度 | 服务器前面板进风温度 | `ipmitool sdr type Temperature` |
| 硬盘温度 | 硬盘盘体或 SMART 报告温度 | `ipmitool sdr type Temperature` 或 `smartctl -A` |
| 主板热点温度 | 主板芯片组（PCH/Chipset）温度 | `ipmitool sdr type Temperature` |
| 风扇转速 | 各风扇模块当前转速（RPM） | `ipmitool sdr type Fan` |
| 风扇冗余状态 | 风扇模块在位状态和健康状态 | `ipmitool sdr type Fan` 或 `ipmitool sdr list` |
| 12V 电压 | 主板、硬盘、PCIe 设备主供电 | `ipmitool sdr type Voltage` |
| 5V 电压 | USB、部分芯片组供电 | `ipmitool sdr type Voltage` |
| 3.3V 电压 | 内存、芯片组辅助供电 | `ipmitool sdr type Voltage` |
| CPU 核心电压 | CPU 核心供电电压（Vcore） | `ipmitool sdr type Voltage` |
| 内存电压 | DDR 内存供电电压（VDD/VPP） | `ipmitool sdr type Voltage` |

## 3. 判定标准

### 3.1 IPMI 传感器状态定义

IPMI v2.0 规范定义了传感器读取时的状态字节，与本系统严重等级的映射关系如下：

| IPMI 状态 | 英文全称 | 含义 | 本系统映射 |
|:--------:|----------|------|:--------:|
| `ok` | OK | 传感器读数在正常范围内 | 🟢 正常 |
| `nc` | Non-Critical | 读数超过非严重阈值上限或下限 | 🟡 预警 |
| `cr` | Critical | 读数超过严重阈值上限或下限 | 🔴 严重 |
| `nr` | Non-Recoverable | 读数超过不可恢复阈值，硬件可能已损坏 | 🔴 严重 |
| `ns` | Not Supported | 传感器不支持该阈值判断 | —（忽略） |

### 3.2 温度判定标准

参考项目设计书 §4.4 阈值定级：

| 传感器类型 | 🟢 正常 | 🟡 预警 | 🔴 严重 | 处置方向 |
|-----------|---------|---------|---------|---------|
| CPU 温度 | <75°C | 75–95°C | ≥95°C | 严重：检查散热硅脂/散热器/机房空调 |
| 进风口温度 | <35°C | 35–45°C | ≥45°C | 严重：检查机房空调/通风地板 |
| 硬盘温度 | <50°C | 50–60°C | ≥60°C | 严重：检查硬盘散热风道 |
| 主板热点温度 | <60°C | 60–75°C | ≥75°C | 严重：检查机箱整体散热 |

### 3.3 风扇判定标准

参考项目设计书 §4.4 阈值定级：

| 指标 | 🟢 正常 | 🟡 预警 | 🔴 严重 |
|------|---------|---------|---------|
| 风扇转速 | RPM > 最低安全阈值 | RPM < 最低安全阈值 | RPM = 0（停转） |
| 风扇冗余 | 所有在位风扇正常运转 | 单个风扇故障（其余正常） | 多个风扇故障或冗余失效 |

说明：最低安全阈值因风扇型号而异，由 BMC 固件预设。当 IPMI 状态为 `nc` 时对应预警，`cr` 或 `nr` 时对应严重。

### 3.4 电压判定标准

参考项目设计书 §4.4 阈值定级。电压偏离度计算公式：**偏离度 = |实际值 - 标准值| / 标准值 × 100%**

| 电压类型 | 标准值 | 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|--------|---------|---------|---------|
| 12V | 12.00V | ≤±5%（11.40–12.60V） | ±5%–10% | >±10%（<10.80V 或 >13.20V） |
| 5V | 5.00V | ≤±5%（4.75–5.25V） | ±5%–10% | >±10%（<4.50V 或 >5.50V） |
| 3.3V | 3.30V | ≤±5%（3.14–3.47V） | ±5%–10% | >±10%（<2.97V 或 >3.63V） |
| CPU 核心电压 | 因型号而异 | ≤±3% | ±3%–6% | >±6% |
| 内存电压 | 因型号而异 | ≤±3% | ±3%–6% | >±6% |

### 3.5 联合判定规则

当同一服务器出现多个传感器同时告警时，按以下规则综合判定：

| 场景 | 判定逻辑 |
|------|---------|
| 温度告警 + 风扇告警同时出现 | 优先处理风扇故障（风扇是根因，温度是表象） |
| 多路电压同时偏离 | 大概率 PSU 整体故障，判定为严重 |
| CPU 温度 + CPU 核心电压同时异常 | 可能是 CPU VRM 故障，判定为严重 |
| 进风口温度正常但 CPU 温度高 | 排除机房环境问题，聚焦 CPU 散热器/硅脂 |
| 同机箱多硬盘温度同时偏高 | 判定为系统级散热问题，非硬盘单体故障 |

## 4. 处置建议

### 4.1 温度预警处置

| 场景 | 处置步骤 |
|------|---------|
| 所有温度预警 | ① 检查对应区域通风是否受阻；② 检查相关风扇是否积尘或转速不足；③ 记录温度趋势，若持续上升则升级为严重；④ 安排维护窗口进行除尘和散热检查 |

### 4.2 温度严重处置

| 场景 | 处置步骤 |
|------|---------|
| CPU 温度 ≥95°C | ① 立即检查 CPU 散热器是否松动；② 检查散热硅脂是否干涸；③ 检查 CPU 风扇是否停转；④ 若散热正常但仍高温，可能是 CPU 内部短路，立即更换 CPU |
| 进风口温度 ≥45°C | ① 检查机房空调出风口和服务器进风口温差；② 检查地板下送风是否阻塞；③ 考虑将高负载服务器分散布局；④ 若为区域性高温，联系机房设施团队 |
| 硬盘温度 ≥60°C | ① 检查硬盘所在盘位的风道是否畅通；② 对比同机箱其他硬盘温度，判断是否为单体故障；③ 单体温度异常且持续，更换硬盘 |
| 主板热点 ≥75°C | ① 检查芯片组散热片是否松动或脱落；② 检查机箱后部排风扇是否正常；③ 长期高温可能导致主板变形或焊点开裂，需重点关注 |

### 4.3 风扇故障处置

| 场景 | 处置步骤 |
|------|---------|
| 风扇转速预警（低于阈值） | ① 记录当前转速值和最低安全阈值；② 观察趋势，若持续下降则排期更换风扇模块；③ 若转速波动剧烈，可能是风扇轴承老化 |
| 风扇停转（RPM=0） | ① **立即更换**该风扇模块；② 更换前密切监控相关区域温度；③ 若温度 ≥严重阈值，立即对该服务器执行降载或关机；④ 更换后确认转速恢复正常，温度逐步回落 |
| 风扇冗余失效 | ① 立即更换故障风扇模块；② 更换前确保剩余风扇可维持最低散热需求；③ 若剩余风扇不足以维持正常温度，降载或关机 |

### 4.4 电压异常处置

| 场景 | 处置步骤 |
|------|---------|
| 电压偏离预警（5%–10%） | ① 持续记录电压波动趋势；② 若偏离持续扩大，升级为严重；③ 维护窗口排期更换电源模块（PSU） |
| 电压偏离严重（>10%） | ① 立即将该服务器从业务集群中摘除，切换至备机；② 更换故障 PSU；③ 上电复测各路电压恢复正常后复机；④ 若更换 PSU 后电压仍偏离，可能是主板供电电路（VRM）故障，需更换主板 |
| 多路电压同时偏离 | ① 大概率是 PSU 整体故障；② 立即更换 PSU；③ 若更换后仍多路异常，检查主板 VRM 是否损坏 |

## 5. IPMI 日志示例

```text
# ipmitool sdr 温度示例
CPU1 Temp        | 68 degrees C  | ok
CPU2 Temp        | 92 degrees C  | nc          ← 预警（Non-Critical）
Inlet Temp       | 40 degrees C  | ok
PCH Temp         | 78 degrees C  | cr          ← 严重（Critical）

# ipmitool sdr 风扇示例
Fan1             | 4500 RPM      | ok
Fan2             | 0 RPM         | cr          ← 严重（停转）
Fan3             | 800 RPM       | nc          ← 预警（低于最低阈值）

# ipmitool sdr 电压示例
12V              | 10.20 Volts   | cr          ← 严重（偏离 15%）
5V               | 4.85 Volts    | ok
3.3V             | 3.50 Volts    | nc          ← 预警（偏离 6%）
CPU Vcore        | 1.05 Volts    | ok
```

## 6. 日志字段映射（适配本系统解析模块）

系统采集到 IPMI 传感器日志后，自动按以下规则结构化。**必须覆盖项目设计书 §4.3 定义的 7 个核心字段**。

| 日志字段 | 系统提取字段 | 示例值 |
|---------|-------------|--------|
| 传感器大类（Temperature/Fan/Voltage） | `fault_type` | `IPMI_Sensor` |
| 传感器类型 | `component` | `Temperature` / `Fan` / `Voltage` |
| 传感器名称（如 `CPU1 Temp`、`Fan2`、`12V`） | `location` | `CPU1 Temp` / `Fan2` / `12V` |
| IPMI 事件类型（如 `nc`、`cr`） | `error_code` | `nc`（Non-Critical）/ `cr`（Critical） |
| 读数 + 阈值对比描述 | `error_description` | `Reading 92°C exceeds threshold 75°C` |
| IPMI 状态映射 | `severity` | `Warning`（nc）/ `Critical`（cr、nr） |
| 通过 `dmidecode -s system-manufacturer` 获取 | `vendor` | `Dell` / `HPE` / `Huawei` / `Generic` |

### severity 自动判定规则（优先级从高到低）

| IPMI 状态 | 本系统严重等级 | 说明 |
|:--------:|:------------:|------|
| `nr`（Non-Recoverable） | 🔴 严重 | 不可恢复，硬件可能已损坏 |
| `cr`（Critical） | 🔴 严重 | 超过严重阈值 |
