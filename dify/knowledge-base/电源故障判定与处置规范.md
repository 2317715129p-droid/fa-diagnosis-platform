# 电源故障判定与处置规范

## 1. 概述
服务器电源模块（PSU，Power Supply Unit）是服务器供电的核心部件，负责将交流电转换为各硬件组件所需的直流电压。服务器通常采用冗余电源设计（1+1 或 N+1），支持热插拔更换。常见电源故障模式包括：电压输出偏离标准值、电源内部温度过高、电源风扇故障、电源模块完全失效等。电源故障可能导致服务器突然断电或硬件损坏，属于高优先级告警。

## 2. 监控指标
| 指标名称 | 说明 | 采集方式 |
|---------|------|---------|
| 12V 电压 | 主板、硬盘、PCIe 设备主要供电电压 | ipmitool sdr type Voltage |
| 5V 电压 | USB、部分芯片组供电 | ipmitool sdr type Voltage |
| 3.3V 电压 | 内存、芯片组辅助供电 | ipmitool sdr type Voltage |
| CPU 核心电压 | CPU 核心供电电压（Vcore） | ipmitool sdr type Voltage |
| 内存电压 | DDR 内存供电电压（VDD/VPP） | ipmitool sdr type Voltage |
| 电源温度 | PSU 内部温度传感器 | ipmitool sdr type Temperature |
| 电源风扇 | PSU 内置散热风扇转速 | ipmitool sdr type Fan |
| 电源冗余状态 | 双路/多路 PSU 的工作状态 | ipmitool sdr type Power Supply |
| 电源负载率 | 当前输出功率占额定功率百分比 | ipmitool sdr 或 PSU 自带监控 |

## 3. 判定标准
### 3.1 电压偏离判定
电压偏离计算公式：偏离度 = |实际值 - 标准值| / 标准值 × 100%
| 电压类型 | 标准值 | 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|--------|---------|---------|---------|
| 12V | 12.00V | ≤±5%（11.40-12.60V） | ±5%-10% | >±10%（<10.80V 或 >13.20V） |
| 5V | 5.00V | ≤±5%（4.75-5.25V） | ±5%-10% | >±10%（<4.50V 或 >5.50V） |
| 3.3V | 3.30V | ≤±5%（3.14-3.47V） | ±5%-10% | >±10%（<2.97V 或 >3.63V） |
| CPU 核心电压 | 因型号而异 | ≤±3% | ±3%-6% | >±6% |
| 内存电压 | 因型号而异 | ≤±3% | ±3%-6% | >±6% |

### 3.2 电源温度判定
| 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|---------|---------|
| <60°C | 60-75°C | ≥75°C |
温度传感器通常位于 PSU 内部出风口处。温度持续升高意味着散热不良、风扇故障或负载过高。

### 3.3 电源风扇判定
| 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|---------|---------|
| RPM > 最低安全阈值 | RPM < 最低安全阈值 | RPM = 0（停转）|
最低安全阈值由各厂商BMC固件定义，风扇停转极易引发电源过热保护关机。

### 3.4 电源冗余状态判定
| 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|---------|---------|
| 所有 PSU 正常工作 | 单路 PSU 故障/离线 | 多路电源同时故障 |
单路故障仍可短期运行，但失去冗余容错能力；多路故障存在突发断电风险。

### 3.5 电源负载率判定
| 🟢 正常 | 🟡 预警 | 🔴 严重 |
|---------|---------|---------|
| <80% | 80%-95% | >95% |
注：MVP阶段固定此阈值，完整版支持运维后台自定义负载告警阈值。

## 4. 处置建议
### 4.1 预警等级处置
**电压偏离预警（5%-10%）**
1. 持续记录电压波动趋势；
2. 若偏离持续扩大，升级为严重告警；
3 维护窗口排期更换电源模块。

**电源温度预警（60-75°C）**
1. 清理服务器进出风口灰尘；
2. 核查机房空调送风温度；
3. 检查电源风扇转速是否衰减。

**风扇转速预警**
电源风扇无法单独更换，需备件整机替换，择机停机维护。

**单路PSU离线/故障**
1. 重新插拔电源线确认接触；
2. 准备同型号冗余电源，维护窗口热插拔更换。

**负载预警（80%-95%）**
1. 核查服务器高负载业务进程；
2. 评估扩容或业务分流，降低长期高负载运行时长。

### 4.2 严重等级处置
**电压偏离>10%**
1. 业务快速迁移至备用服务器；
2. 立即下电更换故障电源；
3. 上电复测各路电压恢复正常后复机。

**电源温度≥75°C / 风扇停转**
1. 风扇停转需紧急停机更换PSU；
2. 临时调高机房制冷，短时间监控温度，禁止长期高温运行。

**多路电源同时故障**
最高优先级故障，随时整机断电；立即迁移业务，批量更换电源。

**负载>95%**
紧急调度业务降低整机功耗，避免长期满负荷加速电源老化损坏。

## 5. BMC日志字段映射（适配本系统解析模块）
采集BMC SEL、dmesg电源告警日志后，系统自动结构化：
- fault_type：Power
- component：PSU
- location：PSU 1 / PSU 2
- severity：电压/风扇/温度严重故障=🔴严重，其余=🟡预警
- error_description：匹配本文故障描述，作为AI诊断根因依据
