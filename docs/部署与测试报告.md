# 系统部署与测试报告

> 本文档为 FA 智能诊断系统「部署与测试报告」，可作为科技进步奖申报书附件三支撑材料。
> 部署流程以 [离线部署手册](离线部署手册.md) 为准；测试依据项目设计书第九章 9 组标准测试用例。
> **说明**：下表「实际结果」列需在真实部署环境运行后据实填写并附运行截图/日志，本文档给出标准用例与预期结果作为基线。

| 编号 | 测试场景 | 输入日志摘要 | 预期输出结果 |

## 五、部署 Bug 修复记录（摘要）

公网版首次部署于阿里云 ECS 时暴露 6 个连锁 Bug，已修复并形成因果链记录，详见 [部署Bug修复记录.md](部署Bug修复记录.md)：

- **Bug 1**：`"$COMPOSE"` 引号包裹错误 → 改 `$COMPOSE`（12 处）
- **Bug 2**：dify-api 缺 OpenDAL 存储配置 → 补充 `STORAGE_TYPE/OPENDAL_SCHEME/OPENDAL_FS_ROOT`
- **Bug 3**：Bug 2 连锁 → 数据库迁移从未执行 → 手动 `flask db upgrade`（建 77 张表）
- **Bug 4/5**：dify-web API 地址指向容器 localhost / JS 编译时写死 → 改服务名 + 清空 NEXT_PUBLIC_*
- **Bug 6**：阿里云安全组未放行 80/3000/8000 → 控制台加规则

离线版（v2.0）进一步修复 24 项已知问题（前端端口冲突、网络隔离、Ollama URL、插件超时、空数据心跳、swap 自动创建等），部署时无需再手动热改，详见 [离线部署手册](离线部署手册.md) 第八章。

## 六、部署结论

中心端一条命令完成部署，12 个容器全部 `Up`，FA 前端/后端、Dify 控制台、Ollama 均可正常访问；
9 组标准测试用例覆盖 CPU/内存/温度/风扇/未知码/空日志/硬盘/电源等典型场景，预期结果明确。
系统具备在国企内网离线环境快速复制推广能力。
