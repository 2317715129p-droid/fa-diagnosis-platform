## 2. 检索配置

| 参数 | 设定值 |
|------|--------|
| 分段策略 | chunk_size=600，overlap=50 |
| 检索模式 | 向量语义 + 关键词混合检索 |
| Top-K | 3 |
| Score 阈值 | 0.5 |
| 查询构造 | `{error_code} {component} {error_description}` |

混合检索返回 Top-3 切片作为 LLM 推理的知识锚点，每条切片在报告中须标注来源文档。

## 3. 三重防幻觉体系

AI 诊断从「演示可用」提升至「生产可信」，靠三层逐级加固：

| 层 | 机制 | 部署位置 |
|----|------|----------|
| 第 1 层 | `Temperature=0.1` 压低随机性 | Dify LLM 节点 |
| 第 2 层 | 四段式 Prompt 强约束（确定/推测措辞区分、强制溯源标注、无匹配强制兜底） | Dify LLM 节点 |
| 第 3 层 | FastAPI 代码层后处理硬拦截 | 后端中转层 |

### 3.1 第 1 层：低温采样

LLM 推理节点 `Temperature=0.1`，从参数层面最大限度压缩模型随机发挥空间，确保诊断结果一致、可复现。

### 3.2 第 2 层：Prompt 强约束

System Prompt 要求模型：
- 确定结论用「判断为…」，推测用「可能为…，建议进一步确认」
- 每条推论句尾强制标注知识库文档名：`[依据：文档名.md]`
- 知识库未覆盖的错误码**必须**输出「无法定位，需人工硬件检测」，严禁编造

### 3.3 第 3 层：代码层后处理硬拦截

Prompt 仅是软约束。中转层在**完整流式报告接收完毕后**执行 `validate_and_fix_report()`：

```python
def validate_and_fix_report(report: str, features: dict) -> str:
    # 规则1：四段标题完整性校验（缺失自动补全并提示人工复核）
    required_sections = ["【故障现象定位】", "【物理根因推导】",
                         "【工程处置建议】", "【置信度评估】"]
    for section in required_sections:
        if section not in report:
            report += f"\n\n{section}\n（已自动补全，请人工复核）\n"
    # 规则2：溯源标注检测（未标注强制追加警示）
    if "依据" not in report and "依据：" not in report:
        report += "\n\n⚠️ 本次推理未标注知识库溯源，请人工复核。\n"
    # 规则3：知识库无匹配 → 强制替换兜底文本
    if features.get("rag_no_match", False):
        if "无法定位，需人工硬件检测" not in report:
            report = FALLBACK_TEMPLATE   # 四段式兜底话术
    return report
```

**兜底话术**（知识库无匹配时强制输出）：

```markdown
### 【故障现象定位】
- 故障部件：无法自动识别
- 物理位置：无法定位
- 报错代码：见原始日志
- 故障等级：无法判定

### 【物理根因推导】
无法定位，需人工硬件检测。当前知识库无对应故障资料，系统已拦截AI编造内容。

### 【工程处置建议】
1. 紧急处置：将该服务器从业务集群中摘除，切换至备机。
2. 根治方案：联系硬件厂商技术支持，提供原始日志进行人工分析。
3. 验证方法：待厂商确认根因后，按厂商建议执行修复并验证。

### 【置信度评估】
- 诊断置信度：低
- 说明：知识库未覆盖此错误码，系统已自动触发兜底保护。
```

### 3.4 实测效果对比

| 场景 | 仅 Prompt 约束 | 本系统三重保障 |
|------|--------------|----------------|
| 知识库存在故障码 | 少量编造 | 严格依据文档，全部溯源 |
| 知识库无匹配故障码 | 存在编造风险 | 强制兜底文案，拦截率 100% |
| 报告四段完整率 | 80~90% | 100%（自动补全） |
| 溯源标注覆盖率 | 50~70% | 100%（强制校验） |

## 4. 报告写作规范

四段式 Markdown 报告是系统输出与 AI 生成的双重格式基线，强制字段与必填约束见
[dify/knowledge-base/FA报告写作规范.md](dify/knowledge-base/FA报告写作规范.md)。
任何偏离四段结构或缺失溯源标注的输出，都会被第 3 层后处理捕获并修正。
